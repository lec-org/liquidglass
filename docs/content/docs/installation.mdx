## 环境

组件声明支持 React 18 及以上。当前站点使用 React 19 与 Vite。npm 构建产物提供 ESM、CommonJS 与类型声明，无需消费方编译 TSX 或处理 Vite 专有导入。

## 从 npm 安装

```sh
npm install @lec-space/liquidglass@1.0.0
```

## 平台 workspace

Lec Platform 内部开发可以直接使用源码，在应用 `package.json` 中添加：

```json
{
  "dependencies": {
    "@lec-space/liquidglass": "workspace:*"
  }
}
```

然后在 Lec Platform 根目录运行 `pnpm install`，保留源码热更新。

## 使用组件

```tsx
import { Button, Glass } from "@lec-space/liquidglass";

export default function Welcome() {
  return (
    <Glass style={{ padding: 24, borderRadius: 24 }}>
      <h2>你好，Liquid Glass。</h2>
      <Button variant="filled" tint="#087f6f">
        开始创作
      </Button>
    </Glass>
  );
}
```

包入口会在浏览器中注入一次组件 CSS，无需再手动导入 `styles.css`。应用自己的样式放在之后，可以覆盖同等优先级的规则。

## 添加背景

玻璃效果依赖后方内容。渐变、图片和不同色块能比纯白背景更好地表现折射。

在 Safari / Firefox 需要复制背景的实现路径中，用 `data-liquidglass-backdrop` 标记背景元素，详见[兼容性](/docs/compatibility)。

## 受控与非受控

表单组件通常同时提供两种模式：

```tsx
// 非受控：组件内部维护状态。
<Switch defaultChecked />

// 受控：由应用管理状态。
<Switch checked={enabled} onCheckedChange={setEnabled} />
```

为输入与图标按钮提供可访问名称。实际接口以各组件的 API 表格为准。

## 跨仓安装构建产物

在 Lec Platform 或组件子仓根目录运行以下命令，生成可安装的 tarball：

```sh
pnpm --filter @lec-space/liquidglass pack --out /tmp/liquidglass.tgz
```

在其他仓库安装生成的文件即可。产物同时提供 ESM、CommonJS、类型声明和 CSS，应用无需处理组件库源码中的 Vite 专有导入。

```tsx
import { ConfigProvider, Dialog, DataTable } from "@lec-space/liquidglass";
import { ResizableWorkspace } from "@lec-space/liquidglass/workspace";
```

分栏入口是可选功能，需要项目安装 `react-resizable-panels@^4.21.0`。基础组件不会加载面板引擎。
