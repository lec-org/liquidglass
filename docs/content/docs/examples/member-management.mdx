## 页面如何组合

这是使用公开组件 API 的完整页面示例。筛选条件、分页、排序、选中成员与详情状态由页面维护，组件通过 props 和回调协作。

- 在姓名输入框和状态选择器中调整筛选，页面重置到第 1 页。
- 排序先应用到完整的示例数据，再截取当前页；对接服务端时，把相同状态传给查询接口。
- 选中行使用稳定 ID，翻页后仍可保留。
- 「详情」打开 Drawer，关闭后返回原来的列表位置。

示例使用本地数据，复制到项目后可以接入已有请求层。SSO 认证、数据权限和统计口径由项目自己的服务处理。
