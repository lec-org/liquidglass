## 使用说明

Glass 继承原生 div 属性，使用 style 或 className 设置尺寸和圆角。将有层次的背景放在容器后方，才能观察折射效果。

## API

下面的属性从组件 TypeScript 定义生成。继承的原生 DOM 属性按需传入；表格聚焦组件常用属性。
