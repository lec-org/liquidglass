## 关于这个版本

`@lec-space/liquidglass` 是 Lec 的 workspace 组件包，源码基于 [onlymoein/liquidglass v0.14.0](https://github.com/onlymoein/liquidglass/tree/dd81a55b5fb14530073cee6280b8067f51314399)，保留上游 MIT 许可证。

这个站点展示仓库里的实际实现，包括 Lec 为 `Menu` 增加的自定义内容能力。当前包尚未发布到公共 npm，接入方式见[快速开始](/docs/installation)。
